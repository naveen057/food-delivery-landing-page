# 🍔 Food Delivery Landing Page

A responsive food delivery website landing page built using HTML and CSS. The project focuses on creating a clean, user-friendly interface for browsing food categories, exploring menu items, and discovering food delivery options.

## ✨ Features

* Responsive food delivery landing page
* Navigation bar with different sections
* Food category section
* Menu and food item sections
* Attractive card-based layout
* Responsive design for different screen sizes
* Clean and user-friendly interface

## 🛠️ Technologies

* **HTML5**
* **CSS3**
* **Bootstrap**

## 📂 Project Structure

```text
food-delivery-landing-page/
│
├── index.html
├── style.css
└── README.md
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/naveen057/food-delivery-landing-page.git
```

2. Navigate to the project folder:

```bash
cd food-delivery-landing-page
```

3. Open `index.html` in your browser.

No additional installation is required.
